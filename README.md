# LLM Ops Toolkit

A file-based operating process and local session recovery toolkit for Claude, Codex, ChatGPT, and comparable LLM environments. Restore, verify, archive, and manage sessions while keeping project work recoverable and controlled.

## Included tools

- `session-rescue-claude/` restores, browses, and cleans up archived Claude Desktop sessions.
- `session-rescue-codex/` finds, verifies, restores, archives, and recoverably removes local Codex tasks.
- `operating-process/` provides a portable file-based process for project context, operating rules, approval gates, and handoffs.

## Existing repositories

The source repositories remain public for compatibility with existing links, releases, and installs.

- [Session Rescue for Claude](https://github.com/Glenskii/session-rescue-for-claude)
- [Session Rescue for Codex](https://github.com/Glenskii/session-rescue-for-codex)
- [Operating Process Starter Kit](https://github.com/Glenskii/ai-operating-process-starter-kit)

Each included tool retains its own documentation and license information. Start with the README in the folder that matches the tool you intend to use.

## Scope

This repository is a consolidation point. It does not replace a platform's native safety controls, backups, account access, or project-level review.
